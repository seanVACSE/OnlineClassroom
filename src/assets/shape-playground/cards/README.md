# Shape Playground card images

Optional PNG images in this folder replace the icons on the Shape Playground selection cards. Use these exact filenames:

- `free-design.png` — Free Design
- `grades-k-1.png` — Grades K–1
- `grades-2-3.png` — Grades 2–3
- `count-the-shapes.png` — Count the Shapes
- `shape-patterns.png` — Shape Patterns
- `create-a-nametag.png` — Create a Nametag

Square images work best. Cards without an image keep their existing icons. Rebuild and deploy the site after adding or replacing images.

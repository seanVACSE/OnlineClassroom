# Shape Playground backgrounds

Export a Canva design as PNG, JPG, JPEG, or WebP and place it in this folder. Each image automatically appears in the Shape Playground background menu after the site is rebuilt. The filename becomes the menu name; hyphens and underscores become spaces.

The canvas is landscape (1000 x 700). Images are fitted inside it without stretching, so designs with the same proportions fill the canvas. A blank canvas is always available. Work is saved separately for each background in the browser on the current device. Keep filenames unchanged to retain the association with saved work.
